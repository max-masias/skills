# ICP Cheatsheet (rápido)

Un ICP define el perfil de la EMPRESA ideal (no persona), usando:
- Firmographics (industria, tamaño, ubicación) [3](https://www.gartner.com/en/digital-markets/insights/b2b-ideal-customer-profile)[4](https://pipeline.zoominfo.com/marketing/ideal-customer-profile)
- Technographics (stack tecnológico) [4](https://pipeline.zoominfo.com/marketing/ideal-customer-profile)[5](https://www.leadsforge.ai/blog/how-to-define-your-icp-ideal-customer-profile)
- Señales/comportamientos de ajuste (fit) [4](https://pipeline.zoominfo.com/marketing/ideal-customer-profile)

CAGE aporta “fricciones” cross-border:
- Cultural, Administrative, Geographic, Economic [1](https://umbrex.com/resources/frameworks/strategy-frameworks/cage-distance-framework/)[2](https://precallai.com/prompt-engineering-framework)
