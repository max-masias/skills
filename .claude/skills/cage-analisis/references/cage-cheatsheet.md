# CAGE Cheatsheet (Preguntas guía)

CAGE evalúa distancia Cultural, Administrative/Political, Geographic, Economic. [3](https://precallai.com/prompt-engineering-framework)[4](https://www.electronicsforu.com/technology-trends/mastering-prompt-engineering-to-enhance-ai-conversations)

## C — Cultural
- ¿Idioma(s) predominantes? ¿Afecta ventas/soporte/marketing?
- ¿Normas sociales/valores relevantes para el tipo de servicio/producto?
- ¿Preferencias de consumo que obliguen a adaptar oferta?

## A — Administrative / Political
- ¿Regulaciones clave para la industria? (licencias, compliance, datos, importaciones)
- ¿Riesgo legal/contractual? ¿Facilidad de hacer cumplir contratos?
- ¿Barreras institucionales o burocracia relevante?

## G — Geographic
- ¿Distancia física / huso horario? ¿Impacta soporte/operación?
- ¿Infraestructura logística y conectividad (transporte, internet, telecom)?
- ¿Acceso a puertos/rutas, topografía, factores que encarezcan entrega?

## E — Economic
- ¿Niveles de ingreso y disposición a pagar para el servicio/producto?
- ¿Costos laborales y disponibilidad de talento/partners?
- ¿Madurez de infraestructura y capacidad de inversión del mercado?
